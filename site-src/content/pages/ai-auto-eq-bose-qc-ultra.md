ANCBuddy's optional **AI Auto-EQ** changes the 3-band Bass, Mid, and Treble profile of a compatible Bose QC Ultra from the Mac menu bar. It is designed for people searching for a practical Bose QC Ultra EQ workflow on macOS; it is not a system-wide audio processor.

## What AI Auto-EQ is — and is not

| Capability | ANCBuddy behavior |
| --- | --- |
| Adjust Bose QC Ultra Bass, Mid, and Treble | Yes |
| Generate a profile for the current track | Yes, when AI Auto-EQ is enabled |
| Keep daily mode and source controls local | Yes |
| Process every sound produced by macOS | No |
| Control non-Bose headphones | No |
| Replace the Bose app's full settings and firmware tools | No |

## How the Bose EQ workflow works on Mac

1. Turn on **AI Auto-EQ** in ANCBuddy.
2. Play a track that exposes artist, title, and album metadata to macOS.
3. ANCBuddy sends that metadata to its recommendation relay.
4. The relay returns a Bass, Mid, and Treble profile.
5. ANCBuddy applies the values to the connected compatible QC Ultra.
6. The current profile remains visible in the menu-bar panel.

The feature works at the Bose device's 3-band EQ level. It does not insert an audio effect into each Mac application or rewrite the original music file.

## When it is useful

AI Auto-EQ is useful when you want the Bose profile to change with the material you are playing rather than keeping one manual setting for every track. Leave it off when you prefer a fixed EQ or want all daily controls to remain fully local.

Quiet, Aware, Immersion, battery, connection status, and audio-source controls do not require AI Auto-EQ.

## Privacy behavior

AI Auto-EQ is opt-in. When enabled, ANCBuddy sends the current artist, title, and album to ANCBuddy's relay only to generate a 3-band recommendation for that track. Results are cached by a hashed track key, and raw song names are not stored in the recommendation cache.

Read [ANCBuddy privacy](/privacy.html) for the complete distinction between local Bose controls, optional track metadata, trial signup data, and first-party website measurement.

## Limits to understand before using it

- Tracks without usable metadata may not receive a meaningful recommendation.
- The output is limited to Bass, Mid, and Treble rather than a multi-band parametric EQ.
- The feature is specific to compatible Bose QC Ultra hardware.
- Firmware, custom Bose modes, shortcuts, and unsupported product settings remain in the Bose app.
