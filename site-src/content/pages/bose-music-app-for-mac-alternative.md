ANCBuddy is an independent Bose app alternative for everyday QC Ultra control from a Mac. The mobile product now called the **Bose app** was formerly known as the **Bose Music app**; it is still the right tool for firmware and full product setup.

## macOS vs ANCBuddy 2.2.0 vs the Bose app

| Function | macOS | ANCBuddy 2.2.0 | Bose app |
| --- | --- | --- | --- |
| Show the active source | Limited | Yes | Yes |
| Show another connected source | Partial | Yes | Yes |
| Show remembered Bose sources | No | Yes | Yes |
| Switch to a remembered source | Partial | Yes | Yes |
| Start new pairing | Bluetooth Settings | Yes | Yes |
| Turn Multipoint on/off | No | Not advertised | Yes |
| Quiet, Aware, and Immersion | No | Yes | Yes |
| Still and Motion | No | Yes, on compatible devices | Yes |
| Battery status | Partial | Yes | Yes |
| Firmware updates | No | No | Yes |

The macOS column describes built-in Mac controls, which can vary by OS and device state. ANCBuddy's source view is specific to sources remembered by a supported Bose QC Ultra; it is not a generic Bluetooth-device manager.

## Where ANCBuddy is useful

ANCBuddy keeps the repetitive desktop workflow in the menu bar:

- switch Quiet, Aware, and Immersion
- see active, connected, and remembered audio sources
- switch to a remembered device or start Bose pairing
- check battery and connection status
- switch Still and Motion on compatible devices
- optionally apply a track-aware 3-band AI Auto-EQ profile

Read [how Bose QC Ultra audio-source switching works on Mac](/switch-bose-qc-ultra-audio-sources-mac.html) for the source states, pairing flow, and Mac-audio recovery.

## Where the Bose app remains the better tool

Keep the Bose app for:

- firmware updates
- initial product setup
- turning Multipoint on or off
- hardware shortcuts, voice prompts, and settings ANCBuddy does not advertise
- any unsupported feature or device-specific adjustment

Bose documents its mobile app in [Bose Support](https://support.bose.com/s/article/qc-headphonearn-download-the-bose-app?language=en_US). ANCBuddy does not claim to be Bose software or a complete replacement.

## Independent by design

ANCBuddy is not affiliated with, endorsed by, or sponsored by Bose Corporation. It uses Bose names only to describe compatible hardware. See the [facts page](/facts.html) for the exact supported scope.
